# SQL Injection Scanner

A Python-based SQL injection testing tool built for learning and authorized security testing.

## Features

- Baseline HTTP request
- Basic SQLi payload testing
- Boolean-based SQLi comparison
- Time-based SQLi testing
- Response status and length comparison
- Response timing measurement
- JSON scan results
- Command-line arguments

## Usage

```bash
python scanner.py --url "https://example.com/filter" --category "Lifestyle"
